¡Hola! Soy Emanuel Sandoval

Soy Técnico en Desarrollo de Software enfocado en la arquitectura y lógica Backend, con bases sólidas para dar soporte en Frontend.

Mi stack de desarrollo backend incluye el manejo de Python (Flask y Django) y C# con ASP.NET 10. Del lado del cliente, me aseguro de que las aplicaciones sean rápidas y visualmente atractivas implementando JavaScript con Vite, HTML, CSS y Tailwind CSS para un diseño ágil y responsivo.

Me motiva el software bien estructurado, la resolución de problemas técnicos complejos y el aprendizaje continuo. Busco mi primera oportunidad profesional en un equipo donde pueda desplegar mis habilidades y seguir creciendo. ¡Hablemos!
